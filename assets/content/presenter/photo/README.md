## Requisitos para la composición futura

**Decisión posterior del usuario:** no hay versiones de mayor calidad; se utilizará `perfil.png` tal como fue recibido. Las resoluciones de referencia siguientes son orientativas y no constituyen una solicitud de reemplazo. Ajustar el tamaño final a la nitidez disponible.

**Recorte autorizado:** al componer «Sobre mí», se puede ajustar el encuadre de la fotografía para integrarla mejor en el layout. Conservar el rostro y la cabeza completos, mantener las proporciones y revisar la nitidez resultante. Aplicar el encuadre mediante CSS o una copia derivada, sin sobrescribir `perfil.png`. El recorte reduce la resolución útil; evitar ampliaciones innecesarias. No se ha realizado aún.

- Proporción preferida: **1:1**, coherente con la caja de retrato prevista. Conservar rostro y cabeza completos; no estirar la fotografía.
- Formatos admitidos: PNG, JPEG o WebP. Preferir sRGB y el archivo de mayor calidad disponible; no es necesario eliminar el fondo.
- Para una caja de 420 × 420 px a Full HD, mínimo recomendado **420 × 420 px**; preferible **840 × 840 px o más** para pantallas con densidad 2×.
- El archivo recibido funciona técnicamente, pero está por debajo del mínimo de la caja prevista: a 420 px se ampliaría 1,05×. Preferir una versión de mayor resolución o confirmar su uso con esa limitación. A un tamaño de hasta 400 px no requiere ampliación.
- No generar una versión artificial de mayor resolución ni usar imágenes de otras personas como reemplazo.

La decisión sobre el tamaño final se tomará al componer la diapositiva; esta fase solo verifica el recurso.
